# Contributing to mol-platform

Thank you for your interest in contributing to mol-platform! We welcome contributions from the community.

## Development Setup

Please refer to our [Installation Guide](docs/installation.md) for setup instructions.

## How to Contribute

1. Fork the repository
2. Clone your fork: `git clone https://github.com/coccinella-labs/mol-platform.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Write tests for new functionality
6. Ensure all tests pass: `python -m pytest tests/ -v`
7. Commit with conventional commits
8. Push to your fork
9. Create a Pull Request

## Guidelines

- Follow our [Contributing Guide](docs/contributing.md) for detailed guidelines
- Use our [Pull Request Template](.github/PULL_REQUEST_TEMPLATE.md)
- Ensure code follows our style guidelines
- Add tests for new features
- Update documentation as needed

## Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Questions?

If you have questions, open an issue or contact the maintainers.

We appreciate your contributions! 🚀
